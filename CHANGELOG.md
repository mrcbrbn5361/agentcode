# Changelog

All notable changes to AgentCode will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] - 2026-07-25

### Added

#### Core Features
- Initial release of AgentCode
- Intelligent multi-model routing system
- Automatic model selection based on task type
- Support for 7 free AI models

#### Supported Models
- **MiMo-V2.5 Free**: Multimodal support (image, audio, video)
- **DeepSeek V4 Flash Free**: High-speed code generation (126 tokens/s)
- **Laguna S 2.1 Free**: Terminal/CLI task expertise (Terminal-Bench 70.2%)
- **Ling-3.0-flash Free**: Token-efficient inference
- **North Mini Code Free**: Local deployment support
- **Nemotron 3 Ultra Free**: Enterprise-grade with 1M context
- **Big Pickle**: Free daily coding and planning

#### Documentation
- Comprehensive README with English translation
- Detailed SKILL.md with usage examples
- CHANGELOG.md for version tracking
- CONTRIBUTING.md for contributor guidelines
- SECURITY.md for security policies
- Basic usage examples

#### Integration
- OpenCode skills integration
- OpenAgentSkill registry submission
- awesome-opencode PR submission
- GitHub repository with MIT license

### Features
- Smart routing logic based on task analysis
- Multimodal task detection and routing
- Context size-based model selection
- Speed priority optimization
- Cost sensitivity consideration
- Privacy-aware model recommendations

### Configuration
- Flexible skill configuration via opencode.json
- Custom model preference support
- Permission settings
- Default agent configuration
